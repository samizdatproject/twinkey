TwinKey

One identity, two keys you already own: a Bitcoin Cash address and a Nostr key, each signing for the other. Published on ordinary Nostr relays. No account, no identity server.

How it works

      
    
        
  1. BCH → Nostr. The BCH key signs Verifying that I control the following Nostr public key: npub… (Bitcoin Signed Message, the format of Electron Cash and Paytaca).
    2. 
        
  2. Nostr → BCH. The Nostr key signs a NIP-39 list containing ["i", "bch:q…", "<that signature>"].
    3. 
        
  3. Discovery. Any Nostr relay stores it. Look up by key (authors) or by address (#i filter).
    4. 
        
  4. Verification. Check the Nostr signature, rebuild the text from the event's own author, recover the address from the BCH signature. No server is trusted; a relay can hide a link but cannot forge one.
    5. 
        
  5. Login. NIP-98 challenge-response with a one-time URL, plus an optional BCH signature over the same nonce.
